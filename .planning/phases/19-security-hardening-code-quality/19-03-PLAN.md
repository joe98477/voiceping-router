<task type="auto">
  <name>Task 1: Configure code quality tooling and pre-commit hooks</name>
  <files>
    package.json
    .eslintrc.json
    .prettierrc.json
    .husky/pre-commit
    android/build.gradle.kts
    android/app/build.gradle.kts
    android/detekt.yml

  <action>
    **Server-side tooling (prettier + lint-staged + Husky):**

    1. Install dev dependencies:
       ```bash
       npm install --save-dev prettier@3.2.5 husky@9.0.11 lint-staged@15.2.2 eslint-config-prettier@9.1.0
       ```

    2. Create `.prettierrc.json` in project root:
       ```json
       {
         "singleQuote": true,
         "trailingComma": "all",
         "printWidth": 120,
         "tabWidth": 2,
         "semi": true
       }
       ```
       Match existing `.eslintrc.json` style (single quotes, semicolons).

    3. Update `.eslintrc.json` to extend `prettier` config (disables formatting rules that conflict):
       Add `"prettier"` to the end of the `extends` array:
       ```json
       "extends": [
         "eslint:recommended",
         "plugin:@typescript-eslint/recommended",
         "prettier"
       ]
       ```
       Remove the `"indent"` rule from `rules` since prettier handles it.

    4. Add `lint-staged` configuration to `package.json`:
       ```json
       "lint-staged": {
         "src/**/*.ts": [
           "prettier --write",
           "eslint --fix"
         ]
       }
       ```

    5. Initialize Husky: `npx husky init`

    6. Create `.husky/pre-commit` script:
       ```bash
       #!/bin/sh

       # Run lint-staged for server TypeScript code (prettier + eslint)
       npx lint-staged

       # Run ktlint format on staged Android Kotlin files
       if git diff --cached --name-only | grep -q '\.kt$'; then
         cd android && ./gradlew ktlintFormat --daemon 2>/dev/null
         cd ..
         git diff --name-only android/ | xargs -r git add
       fi

       # Run detekt security rules on Android code
       if git diff --cached --name-only | grep -q '\.kt$'; then
         cd android && ./gradlew detekt --daemon 2>/dev/null || exit 1
         cd ..
       fi
       ```
       Make executable: `chmod +x .husky/pre-commit`

    **Android tooling (ktlint + detekt):**

    7. In `android/build.gradle.kts`, add ktlint and detekt plugins:
       ```kotlin
       plugins {
           id("com.android.application") version "9.0.0" apply false
           id("com.google.dagger.hilt.android") version "2.59.1" apply false
           id("com.google.devtools.ksp") version "2.3.5" apply false
           id("org.jetbrains.kotlin.plugin.compose") version "2.2.10" apply false
           id("org.jlleitschuh.gradle.ktlint") version "12.1.0" apply false
           id("io.gitlab.arturbosch.detekt") version "1.23.5" apply false
       }
       ```

    8. In `android/app/build.gradle.kts`, apply the plugins and add detekt dependency:
       ```kotlin
       plugins {
           id("com.android.application")
           id("com.google.dagger.hilt.android")
           id("org.jetbrains.kotlin.plugin.compose")
           id("com.google.devtools.ksp")
           id("org.jlleitschuh.gradle.ktlint")
           id("io.gitlab.arturbosch.detekt")
       }
       ```
       Add to dependencies block:
       ```kotlin
       detektPlugins("io.gitlab.arturbosch.detekt:detekt-formatting:1.23.5")
       ```

    9. Create `android/detekt.yml` with security-focused rules:
       ```yaml
       build:
         maxIssues: 0

       formatting:
         active: true
         autoCorrect: true

       potential-bugs:
         active: true
         UnsafeCallOnNullableType:
           active: true

       style:
         active: true
         MagicNumber:
           active: false
         MaxLineLength:
           active: false
         WildcardImport:
           active: false
         ReturnCount:
           active: false
         ForbiddenComment:
           active: false
         UnusedImports:
           active: true
         UnusedPrivateMember:
           active: true

       complexity:
         active: true
         LongMethod:
           active: false
         LongParameterList:
           active: false
         ComplexMethod:
           active: false
         TooManyFunctions:
           active: false
         LargeClass:
           active: false

       exceptions:
         active: true
         TooGenericExceptionCaught:
           active: false
       ```
       Disable noisy rules (MagicNumber, MaxLineLength, LongMethod, etc.) to avoid overwhelming the codebase. Enable security-relevant rules (UnsafeCallOnNullableType, UnusedImports, UnusedPrivateMember).

    **Note:** The `build:maxIssues: 0` may need adjusting if detekt finds many pre-existing issues. If `./gradlew detekt` fails due to too many issues, change `maxIssues` to a higher value (e.g., `-1` to disable) for the initial run. Tighten after cleanup in Task 2.
  </action>
