   After server grants PTT (response.error == null), replace the current direct calls to createSendTransport/startProducing with a retry loop:

   ```kotlin
   // Producer creation with retry (2 retries = 3 total attempts)
   val maxRetries = 2
   var lastError: Exception? = null
   var producerCreated = false

   for (attempt in 0..maxRetries) {
       // Check PTT state each iteration — user may have cancelled
       if (_pttState.value !is PttState.Transmitting) {
           Log.d(TAG, "PTT state changed during retry, aborting")
           return@launch
       }

       try {
           if (attempt > 0) {
               val delayMs = (1000L * (1 shl (attempt - 1))) // 1s, 2s
               Log.d(TAG, "Retry attempt $attempt/$maxRetries after ${delayMs}ms")
               delay(delayMs)
           }

           mediasoupClient.createSendTransport(channelId)
           mediasoupClient.startProducing()
           producerCreated = true
           Log.d(TAG, "Producer created on attempt ${attempt + 1}")
           break
       } catch (e: Exception) {
           lastError = e
           Log.w(TAG, "Producer creation failed (attempt ${attempt + 1}/${maxRetries + 1}): ${e.message}")
       }
   }

   if (producerCreated) {
       onPttGranted?.invoke()
       // Toggle mode timer (existing code)
   } else {
       // All retries exhausted
       Log.e(TAG, "Producer creation failed after ${maxRetries + 1} attempts: ${lastError?.message}")
       _pttState.value = PttState.Error(lastError?.message ?: "Unable to transmit")
       onPttError?.invoke()

       // Auto-release to Idle after brief error display (500ms, same as Denied)
       delay(500)
       _pttState.value = PttState.Idle

       // Stop foreground service since we can't transmit
       val stopIntent = Intent(context, AudioCaptureService::class.java).apply {
           action = AudioCaptureService.ACTION_STOP
       }
       context.startService(stopIntent)
   }
   ```

**HapticFeedback.kt — Double-buzz error release pattern:**

1. Add `vibrateErrorRelease()` method — distinct from existing `vibrateError()` (which is buzz-pause-buzz for denied). The error release is a double-buzz pattern per user decision "Distinct haptic pattern (double-buzz) on failed PTT release vs normal release":

   ```kotlin
   /**
    * Vibrate on PTT error release - double-buzz pattern.
    *
    * Pattern: Strong buzz (80ms), pause (60ms), strong buzz (80ms)
    * Purpose: Distinct from normal release (subtle pulse) and denied (buzz-pause-buzz)
    * Signals that PTT transmission failed after retry attempts
    */
   fun vibrateErrorRelease() {
       try {
           if (vibrator?.hasVibrator() == true) {
               val timings = longArrayOf(0, 80, 60, 80)
               val amplitudes = intArrayOf(0, 255, 0, 255) // Full amplitude for urgency
               val effect = VibrationEffect.createWaveform(timings, amplitudes, -1)
               vibrator.vibrate(effect)
               Log.d(TAG, "PTT error release vibration triggered")
           }
       } catch (e: Exception) {
           Log.e(TAG, "Error vibrating on PTT error release", e)
       }
   }
   ```

2. Add `playConfirmationTone(success: Boolean)` method using the new confirmation tone toggle (independent of roger beep):

   ```kotlin
   /**
    * Play confirmation tone after server ACK — pitch varies by success/failure.
    *
    * Success: DTMF_0 (1336 Hz + 941 Hz) for 150ms — same as roger beep pitch
    * Failure: DTMF_7 (1209 Hz + 852 Hz) for 150ms — lower pitch indicates problem
    * Configurable: Yes (independent "Confirmation tone" toggle in settings)
    * Purpose: Audio feedback when screen is off/headset — confirms transmission was received
    */
   fun playConfirmationTone(success: Boolean) {
       try {
           if (settingsRepository.getCachedConfirmationToneEnabled()) {
               val tone = if (success) ToneGenerator.TONE_DTMF_0 else ToneGenerator.TONE_DTMF_7
               toneGenerator?.startTone(tone, 150)
               Log.d(TAG, "Playing confirmation tone: ${if (success) "success" else "failure"}")
           }
       } catch (e: Exception) {
           Log.e(TAG, "Error playing confirmation tone", e)
       }
   }
   ```
