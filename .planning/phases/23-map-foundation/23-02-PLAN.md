```css

  position: relative;
```

Changed from `aspect-ratio: 4/3; width: 100%; transition: opacity 300ms ease;` — user decision is edge-to-edge filling, not fixed aspect ratio. The `position: relative` is needed because Leaflet uses absolute positioning for its panes. `min-height: 0` prevents flexbox overflow.

**Important: Leaflet invalidateSize consideration.**
When the channels panel collapses/expands, the map panel width changes. Leaflet needs `map.invalidateSize()` to recalculate tile positions. Options:
- Option A: Use ResizeObserver on map-container to detect size changes and call invalidateSize
- Option B: Leaflet 1.9+ has built-in support for CSS transitions via the `invalidateSize` method

Implement Option A as it is more reliable:
- In MapView.jsx, add a ResizeObserver in the useEffect that watches `containerRef.current`
- On resize: call `mapRef.current.invalidateSize()` (if map exists)
- Clean up observer in the useEffect return
