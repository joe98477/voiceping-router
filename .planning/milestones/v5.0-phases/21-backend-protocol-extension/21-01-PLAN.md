    **2.2. Add LOW_BATTERY_ALERT hysteresis logic:**
    Add a private Map: `lowBatteryAlertSent = new Map<string, boolean>()` tracking per-user alert state.

    In `broadcastLocation()`, after broadcasting, check for low battery alert:
    1. If `batteryPercentage` is null → skip (no data)
    2. If `batteryPercentage < 20` AND `lowBatteryAlertSent.get(userId) !== true`:
       - Set `lowBatteryAlertSent.set(userId, true)`
       - Send LOW_BATTERY_ALERT message to dispatch: `{ type: 'low-battery-alert', data: { userId, batteryPercentage, userName: location.userId } }`
       - Log the alert
    3. If `batteryPercentage >= 20` AND `lowBatteryAlertSent.get(userId) === true`:
       - Set `lowBatteryAlertSent.set(userId, false)` — reset suppression, alert will fire again if battery drops below 20%
       - No recovery event sent (per user decision)
