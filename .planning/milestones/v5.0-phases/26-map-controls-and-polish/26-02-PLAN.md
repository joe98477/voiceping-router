  <action>
    Create MapSearch.jsx with full autocomplete search functionality:

    **Props:** `{ locations, channels, onSelectUser }`
    - `locations` -- Map from LocationContext (Map<userId, position>)
    - `channels` -- Array from overview.channels (each has id, name, teamId, members)
    - `onSelectUser(userId)` -- callback when user is selected (parent handles flyTo)

    **State:**
    - `searchTerm` (string, starts empty)
    - `isOpen` (boolean, dropdown visibility)
    - `focusedIndex` (number, -1 = none focused)
    - `expandedChannels` (Set of channelId strings, tracks which channel accordions are open)

    **Filtering logic (useMemo, depends on [searchTerm, locations, channels]):**
    - If searchTerm is empty or whitespace, return empty results
    - `term = searchTerm.toLowerCase().trim()`

    **User search:**
    - Iterate `locations` Map values
    - Filter: `position.userName.toLowerCase().includes(term)`
    - Map to objects: `{ type: 'user', id: userId, name: userName, hasLocation: !!(lat && lng), isOnline: !isStale (5-min threshold), teamName, channelNames }`
    - Determine isStale: `(Date.now() - new Date(position.timestamp).getTime()) > 5 * 60 * 1000`
    - Sort by three-tier relevance:
      1. Exact match (name === term) first
      2. Starts with (name.startsWith(term)) second
      3. Contains (rest) third
      4. Within each tier, sort alphabetically

    **Channel search:**
    - Filter overview channels: `channel.name.toLowerCase().includes(term)`
    - Map to objects: `{ type: 'channel', id: channelId, name: channelName, members: [] }`
    - For each matching channel, build members list from `channel.members` array:
      - Extract userId (handle string or object with .userId/.id, matching LocationContext pattern)
      - Look up each member in `locations` Map to get name, location status, online status
      - Members without location data: include with `hasLocation: false`, name from locations or fallback to "User {userId}"

    **Flat results (useMemo):**
    - Build array for keyboard navigation: Users header + user items + Channels header + channel items
    - Channel items: collapsed shows channel name + member count badge. Expanded shows channel name + individual member sub-items
    - When a channel is expanded (in expandedChannels Set), insert member sub-items after the channel item
    - Mark sub-items as `type: 'channel-member'` with same user fields (id, name, hasLocation, isOnline)

    **Keyboard navigation (handleKeyDown):**
    - ArrowDown: increment focusedIndex, skip headers (`type: 'header'`)
    - ArrowUp: decrement focusedIndex, skip headers
    - Enter:
      - If focused item is `type: 'user'` or `type: 'channel-member'` with hasLocation: call onSelectUser(item.id)
      - If focused item is `type: 'channel'`: toggle channel expansion (add/remove from expandedChannels)
    - Escape: `setIsOpen(false)`, `setFocusedIndex(-1)` -- text stays (per user decision)
    - If dropdown closed and ArrowDown pressed: open dropdown

    **Auto-open:** useEffect on [searchTerm, filteredResults] -- open if term non-empty and results exist, reset focusedIndex

    **Click-away:** useEffect with mousedown listener on document, close if click outside input and dropdown refs

    **Scroll into view:** When focusedIndex changes, scroll the focused item into view using `element.scrollIntoView({ block: 'nearest' })`

    **Render structure:**
    ```jsx
    <div className="map-search" role="combobox" aria-expanded={isOpen} aria-haspopup="listbox">
      <input
        ref={inputRef}
        type="text"
        value={searchTerm}
        onChange={e => setSearchTerm(e.target.value)}
        onKeyDown={handleKeyDown}
        onFocus={() => searchTerm.trim() && results exist && setIsOpen(true)}
        placeholder="Search users or channels..."
        className="map-search__input"
        aria-autocomplete="list"
        aria-controls="map-search-dropdown"
        aria-activedescendant={focusedIndex >= 0 ? `search-result-${focusedIndex}` : undefined}
      />
      {isOpen && flatResults.length > 0 && (
        <div ref={dropdownRef} id="map-search-dropdown" role="listbox" className="map-search__dropdown">
          {flatResults.map((item, index) => renderItem(item, index))}
        </div>
      )}
    </div>
    ```

    **Item rendering:**
    - Headers: `<div className="map-search__header">{item.label}</div>` (not focusable)
    - Users: `<div className="map-search__result {focused?} {disabled?}" role="option">`
      - Name span with matched text highlighted (bold the matching substring -- Claude's discretion)
      - Online/offline dot: green circle for online, gray circle for offline
      - "No location" label for users without hasLocation
    - Channels: `<div className="map-search__result map-search__result--channel">`
      - Channel name + member count badge + expand/collapse chevron
      - onClick: toggle expandedChannels
    - Channel members (sub-items): `<div className="map-search__result map-search__result--member">`
      - Indented (padding-left: 24px)
      - Same format as user items (name, status dot, no-location label)

    **Match highlighting:** Wrap the matched substring in `<strong>` tags. Split name at match position, render prefix + `<strong>match</strong>` + suffix.

    **Debounce:** Not needed per research (200ms debounce only if performance issues). Direct filtering on every keystroke is fine for dispatch scale (< 500 users).
