    **PopupSettingsPanel.jsx** -- Slide-out panel with toggle switches:

    Default settings constant (export for reuse):
    ```javascript
    export const DEFAULT_POPUP_SETTINGS = {
      showLocation: true,
      showMotion: true,
      showChannel: true,
      showPTTStatus: true,
      showConnection: true,
      showBattery: true,
    };
    ```
    Note: userName always shown (not toggleable per user decision).

    **Props:** `{ isOpen, onClose, settings, onSettingsChange, onReset }`
    - `isOpen` -- boolean controlling panel visibility
    - `onClose` -- callback to close panel
    - `settings` -- current settings object (from useLocalStorage in parent)
    - `onSettingsChange(field)` -- callback to toggle a specific field
    - `onReset` -- callback to reset all settings to defaults

    **Panel ref** for click-away detection:
    - useEffect: when isOpen, add mousedown listener on document after 100ms delay
    - Check if click target is inside panelRef -- if not, call onClose()
    - Clean up listener on close or unmount

    **Toggle fields array** (for DRY rendering):
    ```javascript
    const TOGGLE_FIELDS = [
      { key: 'showLocation', label: 'Location (coordinates, accuracy)' },
      { key: 'showMotion', label: 'Motion State' },
      { key: 'showChannel', label: 'Channel Membership' },
      { key: 'showPTTStatus', label: 'PTT Status' },
      { key: 'showConnection', label: 'Connection Quality' },
      { key: 'showBattery', label: 'Battery Level' },
    ];
    ```

    **Render structure:**
    ```jsx
    <div ref={panelRef} className={`settings-panel ${isOpen ? 'settings-panel--open' : ''}`}>
      <div className="settings-panel__header">
        <h3 className="settings-panel__title">Popup Fields</h3>
        <button className="settings-panel__close" onClick={onClose} aria-label="Close settings">x</button>
      </div>

      <div className="settings-panel__description">
        Choose which fields appear in marker popups. Tooltips are not affected.
      </div>

      {/* Non-toggleable field */}
      <div className="settings-panel__field settings-panel__field--fixed">
        <span className="settings-panel__label">User Name</span>
        <span className="settings-panel__always-on">Always shown</span>
      </div>

      {/* Toggleable fields */}
      {TOGGLE_FIELDS.map(field => (
        <div key={field.key} className="settings-panel__field">
          <label className="settings-panel__label" htmlFor={`toggle-${field.key}`}>{field.label}</label>
          <input
            type="checkbox"
            id={`toggle-${field.key}`}
            className="settings-panel__toggle"
            checked={settings[field.key] ?? true}
            onChange={() => onSettingsChange(field.key)}
          />
        </div>
      ))}

      <button className="settings-panel__reset" onClick={onReset}>
        Reset to Defaults
      </button>
    </div>
    ```

    **LocationContext.jsx -- modify generatePopupContent:**

    Change the function signature to accept an optional second parameter `settings`:
    ```javascript
    export function generatePopupContent(position, settings) {
    ```

    If `settings` is undefined/null, behave exactly as before (all fields shown) -- backward compatible.

    When settings is provided, conditionally include sections:

    **Identity section** (always shown):
    - Name: always shown (per user decision)
    - Team: always shown (part of identity, not toggleable)
    - Channels: only if `settings.showChannel !== false`

    **Status section:**
    - Battery: only if `settings.showBattery !== false`
    - Connection: only if `settings.showConnection !== false`
    - Latency: only if `settings.showConnection !== false` (grouped with connection)
    - If all status fields hidden, omit the entire Status section and its divider

    **Activity section:**
    - Motion: only if `settings.showMotion !== false`
    - Speed: only if `settings.showLocation !== false` (speed is part of location/motion data)
    - Updated: always shown (not toggleable -- dispatchers always need recency info)
    - If all activity fields except Updated hidden, still show section with just Updated

    **PTT button:**
    - Only if `settings.showPTTStatus !== false`

    Use `!== false` check (not `=== true`) so that missing fields default to ON (per user decision: "new fields get defaults").

    Important: Do NOT change `generateTooltipContent` -- tooltips stay unchanged regardless of settings (per user decision).

      ```jsx

        onSettingsChange={handleToggleSetting}
        onReset={resetPopupSettings}
      />
      ```

    **Live popup content updates with settings:**
    - In the marker rendering useEffect, pass `popupSettings` to `generatePopupContent`:
      - Where new markers are created: `marker.bindPopup(generatePopupContent(position, popupSettings), ...)`
      - Where existing open popups are updated: `existingMarker.getPopup().setContent(generatePopupContent(position, popupSettings))`
    - In the `popupopen` handler (where the 2-second interval runs), also pass settings:
      `this.getPopup().setContent(generatePopupContent(latest, popupSettingsRef))`
      - IMPORTANT: Since the popupopen handler captures settings in a closure, we need a ref. Add `const popupSettingsRef = useRef(popupSettings);` and keep it in sync via useEffect: `useEffect(() => { popupSettingsRef.current = popupSettings; }, [popupSettings]);`
      - In the interval callback, use `popupSettingsRef.current` instead of `popupSettings`
    - Add `popupSettings` to the dependencies of the marker rendering useEffect so that settings changes re-render popup content for all markers
