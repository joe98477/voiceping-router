<task type="auto">
  <name>Task 2: Create MapView.jsx with full Leaflet map functionality</name>
  <files>web-ui/src/components/MapView.jsx</files>
  <action>
Create `web-ui/src/components/MapView.jsx` — a React component that encapsulates the full Leaflet map.

**Component signature:** `const MapView = ({ eventId }) => { ... }` — receives `eventId` for scoped localStorage keys.

**CSS imports (at top of file):**
```javascript
import 'leaflet/dist/leaflet.css';
import 'leaflet-minimap/dist/Control.MiniMap.min.css';
```
Note: `leaflet-mouse-position` CSS may need manual import — check if `leaflet-mouse-position/src/L.Control.MousePosition.css` exists, otherwise inline the minimal styles needed.

**Refs:**
- `mapRef` (useRef, null) — stores L.Map instance (NOT useState to avoid re-renders)
- `containerRef` (useRef, null) — DOM element ref for the map container div

**Constants:**
- `DEFAULT_CENTER = [-33.8688, 151.2093]` (Sydney, Australia fallback)
- `DEFAULT_ZOOM = 12` (city level)
- `GEOLOCATION_TIMEOUT = 5000` (5 seconds per discretion)
- `STORAGE_KEY = \`cv.dispatch.map.${eventId}\`` (scoped per event per research recommendation)

**Map initialization (useEffect with [] deps):**
1. Guard: if `containerRef.current` is null or `mapRef.current` is already set, return
2. Restore saved state from localStorage (try/catch, parse JSON, extract center/zoom/layer)
3. Create map: `L.map(containerRef.current, { ... })`
   - `center`: restored center OR DEFAULT_CENTER
   - `zoom`: restored zoom OR DEFAULT_ZOOM
   - `keyboard: false` (disabled per user decision — avoid conflicts with app shortcuts)
   - `scrollWheelZoom: true`
   - `doubleClickZoom: true`
   - `zoomControl: false` (will add manually at bottom-right)
   - `attributionControl: false` (will add manually collapsed)

4. **Tile layers (locked decisions):**
   - Satellite base: `L.tileLayer('https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}', { attribution: 'Esri, Maxar, Earthstar Geographics' })`
   - Labels overlay: `L.tileLayer('https://services.arcgisonline.com/ArcGIS/rest/services/Reference/World_Boundaries_and_Places/MapServer/tile/{z}/{y}/{x}', { attribution: '' })`
   - Satellite with labels: `L.layerGroup([satelliteBase, labelsOverlay])`
   - Street: `L.tileLayer('https://tile.openstreetmap.org/{z}/{x}/{y}.png', { attribution: '\u00a9 OpenStreetMap contributors' })`
   - Add restored layer OR satellite (default) to map

5. **Layer control (locked: Leaflet default, top-right):**
   - `L.control.layers({ 'Satellite': satelliteWithLabels, 'Street': streetLayer }, null, { position: 'topright' }).addTo(map)`

6. **Zoom control (locked: bottom-right):**
   - `L.control.zoom({ position: 'bottomright' }).addTo(map)`

7. **Scale bar (locked: metric, on map):**
   - `L.control.scale({ position: 'bottomleft', imperial: false }).addTo(map)`

8. **Attribution (locked: collapsed by default):**
   - `L.control.attribution({ position: 'bottomright', prefix: false }).addTo(map)`
   - Set collapsed attribute via DOM after add if Leaflet supports it, or use CSS to collapse

9. **Mouse position / coordinates display (locked: decimal degrees, bottom-left):**
   - Import and use `L.control.mousePosition` from leaflet-mouse-position plugin
   - `L.control.mousePosition({ position: 'bottomleft', separator: ', ', lngFirst: false, numDigits: 4, emptyString: '' }).addTo(map)`
   - If the plugin import fails at runtime, implement a simple fallback: listen to `map.on('mousemove')` and update a custom DOM element

10. **Minimap (locked: capability included, off/collapsed by default):**
    - Import MiniMap from leaflet-minimap
    - Create minimap tile layer (OSM street tiles for contrast with satellite)
    - `new L.Control.MiniMap(minimapTileLayer, { position: 'bottomright', width: 150, height: 150, zoomLevelOffset: -5, toggleDisplay: true, minimized: true }).addTo(map)`

11. **Geolocation (locked: silent, no UI, 5s timeout, Sydney fallback):**
    - Only if NO saved state was restored from localStorage
    - Check `'geolocation' in navigator`
    - Call `navigator.geolocation.getCurrentPosition(success, error, { timeout: 5000, enableHighAccuracy: false, maximumAge: 300000 })`
    - Success: `map.setView([lat, lng], DEFAULT_ZOOM)`
    - Error/timeout: map already initialized with DEFAULT_CENTER, no action needed

12. **localStorage persistence (locked: save center + zoom + layer, restore on reload):**
    - Track active layer name in a variable (use closure or ref): `'satellite'` or `'street'`
    - Listen for `baselayerchange` event on map to update active layer tracking
    - Listen for `moveend` and `zoomend` events to save state
    - Save function: `localStorage.setItem(STORAGE_KEY, JSON.stringify({ center: [lat, lng], zoom, layer: activeLayerName }))`
    - Debounce saves aren't necessary — moveend/zoomend fire once per interaction

13. **Cleanup (CRITICAL for React Strict Mode):**
    - useEffect return function must:
      - Remove all event listeners (moveend, zoomend, baselayerchange)
      - Call `mapRef.current.remove()` (destroys map, clears all listeners and DOM)
      - Set `mapRef.current = null`

**Render:**
```jsx
return <div ref={containerRef} style={{ width: '100%', height: '100%' }} />;
```

**Important implementation notes:**
- Do NOT use useState for map instance (triggers re-renders on every mutation)
- Use useRef for tracking activeLayerName to avoid stale closures in event handlers
- The component renders a simple div — Leaflet manages everything inside it
- Grey placeholder tiles while loading is handled automatically by Leaflet (browser renders grey before tile images load)
- Tile caching is automatic via browser HTTP cache (Esri/OSM tiles have cache-friendly headers)
